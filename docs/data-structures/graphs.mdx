# Graphs

1. Directed and Undirected - Means either one way or two-way connection.
2. Cyclic and Acyclic - Meaning if the graph has cyclic relation between its nodes.
3. Connected and Non-Connected Graph - Whether all nodes in the graph is reachable from other nodes of the graph.

:::important Graphs have no root
Unlike trees, graphs don't have any root node.
In all problems, ideally any node can be treated as root or starting point in the graph.
:::

## Concept of Degrees

Degree is a graph refers to the number of connections a node has in the graph.

- **undirected graph** - degree is the number of edges connected to the node.
- **directed graph** - This has two different degrees. **In-degree** refers to the number of incoming connections,
  and **out-degree** refers to the number of outgoing connections.
