# Shell

Shell is an application that provides a way to interact with the kernel.

:::important why the name shell?
The kernel is the core and the only way to interact with it's via C programs.
The core is covered and protected by shell which lets users interact with kernel in a safe and easy way.
:::

If there is no shell, the only way to execute something would be through C or other programming languages.
For example, Java has ProcessBuilder for the same reason.
