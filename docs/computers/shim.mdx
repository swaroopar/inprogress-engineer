# Shim

A shim is an intermediate layer. It fills the gap between two things.

:::important What's a shim?
A shim is a physical object inserted between two things when a gap exists.
For example, a piece of paper, metal, or wood inserted under chair legs stops wobbling.
:::

## Examples of Shims

1. **Docker Shim** - Helps the Docker daemon control containers.
2. **Python Shim** - Helps you choose and use different Python versions.
3. **Adapter Shim** - Code that connects different API versions.
